Privacy Policy

Effective Date: August 28, 2026

1. Information Collected

AppManager collects account credentials, email addresses (for magic link authentication), API access tokens, system performance logs, and operational telemetry required to manage installed applications.

Information is processed solely to authenticate users, grant application access permissions, maintain system health, and secure platform endpoints.

3. Data Protection

Personal data and API tokens are stored using industry-standard security safeguards. Data is never sold or shared with third-party advertisers.

4. Contact

For privacy inquiries or account data management, please contact your system administrator.
